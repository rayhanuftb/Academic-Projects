# Data Structures and Algorithm Lab

**Course Code:** ICT 4156  
**Academic Level:** Undergraduate (B.Sc. in Educational Technology and Engineering)  
**Institution:** University of Frontier Technology, Bangladesh

---

## 📘 Course Overview

The **Data Structures and Algorithm Lab** covers fundamental abstract data types, stack-based algorithm design, recursion, expression parsing, tree traversals, and asymptotic complexity analysis.

---

## 📂 Laboratory Projects

### 1. [Expression Converter](./Expression%20Converter/)
- **Objective:** Stack-based expression converter (Infix, Postfix, Prefix) using the Shunting-Yard algorithm and arithmetic evaluator with operator precedence, associativity handling, and $O(N)$ computational efficiency.
- **Technologies:** Python, Stack Data Structures, Regex.
- **Artifacts:** Source code (`src/`), CLI tool (`main.py`), and automated unit tests (`tests/`).
