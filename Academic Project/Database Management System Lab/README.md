# Database Management System Lab

**Course Code:** ICT 4254  
**Academic Level:** Undergraduate (B.Sc. in Educational Technology and Engineering)  
**Institution:** University of Frontier Technology, Bangladesh

---

## 📘 Course Overview

The **Database Management System Lab** focuses on relational schema design, SQL DDL/DML, normalization (1NF through 3NF/BCNF), integrity constraints, transactional consistency, and database-backed full-stack web applications.

---

## 📂 Laboratory Projects

### 1. [UFTB Hostel Management System](./UFTB%20Hostel%20Management%20System/)
- **Objective:** Full-stack database management system for student residential records, room bed allocations, monthly fee payments, and facility maintenance ticketing.
- **Technologies:** SQLite (`node:sqlite`), Node.js, SQL, HTML5, CSS3, JavaScript.
- **Artifacts:** Relational database schema (`database/schema.sql`), REST API backend (`backend/`), responsive frontend (`frontend/`), and automated test suite (`tests/`).
