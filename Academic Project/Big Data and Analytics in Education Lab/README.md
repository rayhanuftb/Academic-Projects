# Big Data and Analytics in Education Lab

**Course Code:** ICTE 4434  
**Academic Level:** Undergraduate (B.Sc. in Educational Technology and Engineering)  
**Institution:** University of Frontier Technology, Bangladesh

---

## 📘 Course Overview

The **Big Data and Analytics in Education Lab** focuses on applying data science, natural language processing, predictive modeling, and time series forecasting techniques to educational datasets and learning management systems.

---

## 📂 Laboratory Projects

This course directory contains two fully implemented, independent academic projects:

### 1. [Natural Language Processing Analysis](./Natural%20Language%20Processing%20Analysis/)
- **Objective:** Text preprocessing, tokenization, stop-word removal, n-gram extraction, and sentiment polarity classification on educational feedback and course evaluations.
- **Technologies:** Python, Pandas, Matplotlib, NLTK.
- **Artifacts:** Modular pipeline (`src/`), CLI tool (`main.py`), automated tests (`tests/`), dataset, and generated visualizations.

### 2. [Time Series Analysis](./Time%20Series%20Analysis/)
- **Objective:** Longitudinal time series modeling, trend/seasonality decomposition, chronological train-test splitting, and multi-model forecasting (SMA, EMA, AR-p) evaluated via MAE, RMSE, MAPE, and $R^2$.
- **Technologies:** Python, Pandas, NumPy, Matplotlib.
- **Artifacts:** Modular forecasting framework (`src/`), CLI tool (`main.py`), automated tests (`tests/`), synthetic 180-day LMS dataset, and visualization outputs.
