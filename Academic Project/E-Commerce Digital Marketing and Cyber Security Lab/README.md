# E-Commerce, Digital Marketing and Cyber Security Lab

**Course Code:** ICT 4364  
**Academic Level:** Undergraduate (B.Sc. in Educational Technology and Engineering)  
**Institution:** University of Frontier Technology, Bangladesh

---

## 📘 Course Overview

The **E-Commerce, Digital Marketing and Cyber Security Lab** addresses electronic commerce web architecture, catalog presentation, digital marketing optimization (SEO, OpenGraph metadata), and secure web transaction processing.

---

## 📂 Laboratory Projects

### 1. [আভরণ (Abhoron): E-Commerce Website for Clothing and Textiles](./Abhoron%20E-Commerce/)
- **Objective:** Boutique e-commerce platform for Bangladeshi traditional handloom apparel, featuring responsive catalog filtering, shopping cart state management, checkout validation, and SEO digital marketing integration.
- **Technologies:** Node.js, SQLite (`node:sqlite`), HTML5, CSS3, JavaScript.
- **Artifacts:** Storefront application (`frontend/`), REST API backend (`backend/`), database seed (`database/`), and automated test suite (`tests/`).
