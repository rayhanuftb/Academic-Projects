# Visual Storyboard & Production Blueprint

**Project:** Educational Video on Cloud Computing for EdTech  
**Author:** Rayhanul Islam  

---

## 🎨 Scene-by-Scene Visual Storyboard

| Scene # | Timecode | Visual Elements & Animations | Audio / Narration Summary | Production Notes |
|:---:|:---:|---|---|---|
| **01** | `00:00-01:15` | **Title Card**: Dynamic 3D Cloud graphic with glowing network nodes. On-screen text: *"Cloud Computing in Education"*. | Engaging hook on concurrent student traffic during online exams. | Fast cuts, ambient tech background score at -24 dB. |
| **02** | `01:15-03:30` | **Comparison Layout**: Split-screen animation comparing on-premise hardware bottlenecks vs. elastic cloud resource allocation. | Explaining high CapEx and downtime risks of traditional servers. | Animated bar charts contrasting fixed vs. variable scaling costs. |
| **03** | `03:30-06:00` | **Hierarchy Pyramid**: Layer-by-layer reveal of IaaS (Foundation), PaaS (Middle Layer), and SaaS (Top Layer) with icons. | Detailed explanation of IaaS, PaaS, SaaS models with real EdTech platforms. | Smooth camera zoom into each tier as discussed. |
| **04** | `06:00-08:00` | **Interactive Architecture**: End-to-end packet flow from student browser through Cloudflare CDN, Load Balancer, ECS Containers, to Aurora DB. | Top 3 cloud architecture rules: State decoupling, redundancy, auto-scaling. | Blueprint style grid background with moving dashed packet vectors. |
| **05** | `08:00-09:30` | **Summary & Call to Action**: Key takeaways bullet points with interactive end screen linking to GitHub repository and Quiz App. | Outro, quiz recommendation, engagement prompt, and subscription reminder. | End screen card overlays configured for YouTube 16:9. |

## 🛠️ Production & Recording Specifications

- **Video Resolution:** 1920x1080 Full HD (1080p60) / 4K UHD
- **Aspect Ratio:** 16:9 Landscape
- **Audio Sample Rate:** 48 kHz / 24-bit Stereo (Broadcast Standard)
- **Voiceover Quality:** Studio cardioid condenser microphone with pop filter & acoustic isolation
- **Video Editing Software:** DaVinci Resolve / Adobe Premiere Pro / OBS Studio
- **Graphic Assets:** Vector diagrams created in Figma / Adobe Illustrator
