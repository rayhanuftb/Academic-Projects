# Digital Content Design and Development Lab

**Course Code:** ICTE 4232  
**Academic Level:** Undergraduate (B.Sc. in Educational Technology and Engineering)  
**Institution:** University of Frontier Technology, Bangladesh

---

## 📘 Course Overview

The **Digital Content Design and Development Lab** investigates multimedia instructional design, interactive educational applications, video scriptwriting, visual storyboarding, and responsive frontend learning tools.

---

## 📂 Laboratory Projects

### 1. [YouTube Learning Content](./YouTube%20Learning%20Content/)
- **Objective:** Professional video production framework on *Cloud Computing in Educational Technology*, featuring learning objectives, a timestamped voiceover script, visual storyboarding, and technical recording standards.
- **Artifacts:** Full script (`script.md`), visual storyboard and production specifications (`storyboard.md`).

### 2. [JavaScript Quiz App](./JavaScript%20Quiz%20App/)
- **Objective:** Interactive single-page quiz application with objective multiple-choice scoring, real-time feedback, explanatory rationale, and progress visualization.
- **Technologies:** HTML5, CSS3, JavaScript (ES6+).
- **Artifacts:** Web application (`index.html`, `styles.css`, `app.js`), question bank (`questions.js`), and automated unit tests (`tests/`).
