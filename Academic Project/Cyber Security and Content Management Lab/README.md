# Cyber Security and Content Management Lab

**Course Code:** ICT 4462  
**Academic Level:** Undergraduate (B.Sc. in Educational Technology and Engineering)  
**Institution:** University of Frontier Technology, Bangladesh

---

## 📘 Course Overview

The **Cyber Security and Content Management Lab** explores network security fundamentals, safe diagnostic auditing, IP address management, and web content protection architectures.

---

## 📂 Laboratory Projects

### 1. [Network Scanning and IP Configuration](./Network%20Scanning%20and%20IP%20Configuration/)
- **Objective:** IPv4 subnet calculation, VLSM hierarchical addressing optimization, and safe local TCP port diagnostic utility with ethical security boundaries.
- **Technologies:** Python, IPv4 Networking Sockets, `ipaddress` library.
- **Artifacts:** Source code (`src/`), CLI tool (`main.py`), automated unit tests (`tests/`), and practical lab execution documentation.
